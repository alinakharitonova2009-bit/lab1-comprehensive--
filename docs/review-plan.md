# План ревью модуля src/discount.py

## 1. Цели ревью
- Точность расчётов итоговой стоимости.
- Защита от фрода (лимит скидки).
- Корректность применения промокодов и уровней лояльности.

## 2. Измеримые критерии
- Нет магических чисел (все коэффициенты — в константах).
- Валидация входных данных.
- Покрытие тестами > 80%.
- flake8 без замечаний, длина строки ≤ 80.

## 3. Участники и роли
| Роль | Ответственный |
|---|---|
| Автор | Разработчик |
| Ревьюер №1 | Tech Lead |
| Ревьюер №2 | QA |

## 4. Процесс
1. PR в develop, CI зелёный.
2. 2 аппрува.
3. Все комментарии resolved.

## 5. Эскалация
1. Комментарии PR → 2. Созвон с Tech Lead → 3. Владелец продукта → 4. ADR.
